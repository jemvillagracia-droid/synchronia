Download **SYNCHRONIA-Setup-1.4.5.exe** (installer) or **SYNCHRONIA-1.4.5-portable.zip** (no install) below. Upgrading keeps your data.

The installer is not code-signed, so Windows SmartScreen may warn. Choose *More info › Run anyway*.

### New
- **Calendar photos:** Academic Calendar › Import school calendar now accepts a photo or screenshot (JPG, PNG, WebP, BMP, TIFF, GIF) as well as Word, PDF and text. The text is read on this computer, offline, and every date is shown for review before anything is saved. iPhone HEIC photos: save them as JPG or PNG first.
- **Backup copy folder:** Settings › *Copy backups to another folder*. Choose a folder that Google Drive or OneDrive keeps on your other computer; each backup is also saved there (the newest 15 are kept). If the folder goes missing, the app says so and never claims a copy was made.
- **Notification settings:** Settings › Workspace › Notifications. Turn the Windows notification and the timer sound on or off.

### Fixed (follow-up to the 2nd quality check)
- **Settings never show a false success:** if a setting cannot be saved, it returns to its saved value and you see "Setting not saved" with the reason.
- **Large archives stay fast to save:** each save used to get slower as the archive grew. Saves now take the same time at any size (50,000 records tested).
- **Very large CV sections:** creating a CV no longer fails when a section has tens of thousands of records.
- **Central Nexus** opens about twice as fast with very large archives.
