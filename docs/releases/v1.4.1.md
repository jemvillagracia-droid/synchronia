Download **SYNCHRONIA-Setup-1.4.1.exe** (installer) or **SYNCHRONIA-1.4.1-portable.zip** (no install) below. Upgrading keeps your data.

The installer is not code-signed, so Windows SmartScreen may warn. Choose *More info › Run anyway*.

### Administrative Operations
- **Daily log:** the entry sits on one line when there is room; in narrower windows it folds into three tidy lines.
- **Correspondence table:** column headings, reference numbers (e.g. MEMO-2026-118) and status tags stay on one line.
- **Needs attention:** each item's due date sits beside it, and its age reads "added today" or "open 3 days".

### One look across every module
- **Page titles:** every page uses the same title style. Editor pages (syllabus, moodboard board, CV) use it one size smaller, and the CV title is no longer in a different font.
- **Controls:** buttons, list filters and pickers have the same height everywhere. Buttons inside tables no longer squeeze onto two lines.
- **Reports and Analytics:** the "Include" label stays next to its choice.
- **Syllabus editor:** the Word and PDF export buttons stay together.
- **Light and Sepia themes:** overdue dates and library warnings are readable.
