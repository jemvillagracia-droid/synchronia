Download **SYNCHRONIA-Setup-1.1.0.exe** (installer) or **SYNCHRONIA-1.1.0-portable.zip** (no install) below.

**Install:** run the installer. It installs per user (no administrator rights). Upgrading from 1.0.0 keeps your data; a snapshot of your database is taken before the update.

**Portable:** download `SYNCHRONIA-1.1.0-portable.zip`, unzip it to a folder you can write to (not Program Files) and start `SYNCHRONIA.exe`. Nothing is installed; your records, backups and settings stay in the `SYNCHRONIA Data` folder beside the program, so the folder can go on a USB drive.

The installer is not code-signed, so Windows SmartScreen may warn. Choose *More info › Run anyway*.

### New
- **Calendar** with Philippine (RA 9492 as amended) and Australian (national + your state) holidays, alongside your deadlines, meetings, classes and talks. Proclamation-dependent dates are marked as estimates and can be corrected.
- **Central Nexus** command deck: status strip, countdowns to your next item and next holiday, calendar monitor.
- **Import from existing CV** (PDF or Word): everything is reviewed before saving and saved as self-reported.
- **Partial dates**: year or month only for historical records; nothing is invented.
- **CV Studio**: Academic and Professional Portfolio CV, a separate resource speakership section, rule-based wording suggestions.
- **Export verification**: every Word, PDF and Excel file is reopened and checked before the app reports it saved.
